# Codex Memory

Эта папка хранит рабочую память проекта ETNA RestForm: продуктовый контекст, архитектуру, интеграции, решения, текущий прогресс, известные риски и ближайший следующий шаг. Она нужна, чтобы в новом диалоге Codex мог быстро продолжить работу без восстановления контекста из длинной переписки.

Если ты Codex в новом диалоге — начни с чтения файлов в порядке номеров.

## Файлы

- `00_README.md` — назначение папки и порядок чтения.
- `01_PROJECT.md` — цель проекта, аудитория, фичи, стадия, основные ссылки.
- `02_STACK.md` — стек, версии локальных инструментов, GitHub Pages, Apps Script, Sheets, Telegram, Fonts, секреты без значений.
- `03_ARCHITECTURE.md` — структура проекта, поток данных, mermaid-диаграмма, точки интеграции.
- `04_CONVENTIONS.md` — соглашения по коду, Git, деплою, файлам и предпочтения владельца.
- `05_ALGORITHMS.md` — бизнес-логика, формулы, обработка дат, ретроввод, Telegram и Sheets.
- `06_DECISIONS.md` — журнал важных решений в формате ADR.
- `07_PROGRESS.md` — сделано, в работе, следующий план, известные баги, открытые вопросы.
- `08_HANDOFF.md` — критический файл передачи контекста: последнее состояние и конкретный следующий шаг.

## Правила

- Не хранить здесь GitHub PAT, Telegram Bot Token, приватные Chat ID, приватные PIN, `.env` и другие секреты.
- Если данных не хватает, писать `<TODO: уточнить у пользователя>`.
- После правок `Code.gs` не считать backend завершённым, пока владелец не создаст новое Apps Script deployment и не даст новый Web App URL.
- Перед изменениями всегда проверять рабочую папку: правильный репозиторий находится в `/Users/rio/Desktop/RestForm`.
- Перед пушем запускать `npm run check`.
