# Project

## Название и цель

ETNA RestForm — мобильная веб-форма закрытия смены для ресторана «ЭТНА». Сотрудник в конце смены открывает форму на телефоне, вводит PIN, заполняет выручку, расходы, инкассацию и остаток кассы; форма считает итоги, сверяет кассу, сравнивает факт с планом, отправляет отчёты в Telegram и записывает данные в Google Sheets.

## Целевая аудитория

- Сотрудники ресторана, закрывающие смену с телефона.
- Руководитель, которому нужны контроль кассы, полный отчёт, фото чеков и аналитика.
- Владелец проекта, который развивает форму через Codex, GitHub Pages, Google Apps Script и Google Sheets.

## Ключевые фичи

- PIN-вход сотрудников.
- Два текущих сотрудника: Даня и Элина. PIN считать чувствительными значениями; не дублировать в публичной документации.
- PIN руководителя для настроек и ретроввода. Значение считать чувствительным.
- Ретроввод на любую дату после PIN руководителя.
- При ретровводе обязательный выбор сотрудника, чья была смена.
- Для обычного сотрудника даты старше 2 дней блокируются полноэкранной плашкой.
- Дата по умолчанию берётся по московскому времени.
- Выбор даты через системный `input[type=date]`.
- Автообновление настроек при старте, при возврате вкладки в фокус и раз в 6 часов.
- Расчёт выручки, безнала, наличных, расходов, инкассации, расчётного остатка и разницы кассы.
- Отдельный блок такси прошлой смены: такси вводится только при оплате картой; при наличной оплате значение `0`.
- Дополнительные расходы с суммой и комментарием.
- Загрузка фото чеков.
- Запись отчётов в Google Sheets.
- Telegram-отчёты: краткий для общего чата, полный для руководителя, фото чеков руководителю.
- Настройки руководителя: Telegram, ставка кальяна, лимит такси, планы по дням, сотрудники.

## Текущая стадия

MVP / beta. Форма уже развёрнута на GitHub Pages и подключена к Apps Script / Sheets / Telegram. Локальная проверка `npm run check` проходит на момент создания памяти. Перед production-нормой нужно убрать оставшийся технический долг: дублирующуюся функцию в `Code.gs`, клиентский Telegram-путь в `index.html`, публичные дефолтные PIN в коде.
